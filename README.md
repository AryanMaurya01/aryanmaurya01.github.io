## Projects

### Interview Copilot
> AI interview practice app with text and camera/voice modes.

- An AI interviewer asks DSA, system design, OOP and behavioural questions.
- Voice pipeline: browser audio capture, Whisper transcription, then DeepSeek evaluation scoring correctness, communication, confidence, optimisation and missing points.
- Saved session history, score-trend analytics and a local fallback evaluator for when the API call fails.

**Tech:** TypeScript, React 19, TanStack Start, Tailwind CSS, Whisper, DeepSeek (via OpenRouter)

[GitHub Repository](https://github.com/HostileCoder006/ai-interview-copilot)

### QuantTrader AI
> Stock analysis and decision-support platform with NIFTY 50 paper trading.

- A deterministic engine (RSI, MACD, VWAP, EMA, ATR) generates the signals; the LLM only explains them.
- Backtester and Strategy Lab reporting Sharpe, Sortino, max drawdown and win rate, with next-bar execution to avoid lookahead bias.
- Market-regime engine, similar-setup search over past OHLCV data, and a multi-analyst AI investment committee.

**Tech:** Python, Flask, SQLite, Pandas, NumPy, yfinance, React, TypeScript, DeepSeek V3.2

> Anomaly detection and health scoring from multi-sensor machine data.

- Uses vibration, temperature, pressure and sound data to detect anomalies and compute a machine health score.
- Real-time Streamlit dashboard to monitor machine performance and surface insights for improving efficiency.

**Tech:** Python, Pandas, Streamlit, Machine Learning
